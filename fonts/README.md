# Console fonts

`proxhawk-256.psf.gz` and `proxhawk-512.psf.gz` are bitmap fonts (PSF2, 8×16)
for the **Linux virtual console** (`TERM=linux`: screen and keyboard of the
node, IPMI / KVM). proxhawk-tui loads one of them while it runs on that
console and puts the previous font back when it quits (`lib/console.sh`,
setting `console_font`).

They hold what the interface displays and the console fonts of Debian lack:
box drawing, block elements, the symbols used as icons, the braille patterns
of the graphs, and the letters of the languages (256: Western European
languages, keeps the 16 colours of the console; 512: Latin Extended,
Cyrillic and Greek as well).

They are generated by `tools/make-console-font.py` from **GNU Unifont**
(<https://unifoundry.com/unifont/>), © Roman Czyborra, Paul Hardy and
contributors, licensed under the GNU GPL version 2 or later with the GNU
font embedding exception, and under the SIL Open Font License 1.1. A few
glyphs that are 16 pixels wide in Unifont (✔ ✖ ✎ ⚙ ⏎ ⊸ ⊶) are redrawn in
8×16 in the tool. The fonts are distributed under the same licences as
Unifont.
